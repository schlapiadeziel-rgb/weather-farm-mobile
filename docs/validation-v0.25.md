# v0.25.0 验证范围

本轮改进小镇三座建筑、列车和静态底景，不修改游戏经济、解锁规则、接待状态机、布局或存档结构；真实农场服务独立保留。

- TypeScript、最终生产构建与 331 项已有规则测试通过。
- 27 组最终生产 App 检查：10 组小镇美术与经营交互、17 组地图回归，使用相同最终构建。
- 在 640×360、844×390、1280×720 检查四张本地透明 WebP 解码和七棵复用树木。建筑按钮和列车外框与已校验公开 v0.24.0 APK 逐项比较相同，无页面横向溢出、额外焦点或装饰点击目标。
- 自然新农场实际迎接列车、交货、等待、领奖，获得 3 声望后以 250 游戏金币建造咖啡馆；连续点击接待和领奖仅结算一次。未触发列车时不自动生成访客，小镇六位访客上限保留。
- 全部图片失败时，三座建筑、列车和七棵树各自回退矢量，仍可迎接与服务；单独咖啡馆图片失败不影响其他素材或切换到旅舍预览。未建建筑继续变淡，声望不足时不能建造。
- 另用三座已建建筑的隔离测试存档，核对每座的实际扣货量、60/90/180 秒服务时长及手动领取报酬；静态美术不提前制造待收提示。
- 减少动态效果时小镇新插画和背景无动画；独立助手切换、返回及重载保留小镇存档和四个真实资料保护字段。美术检查阻断外部 HTTPS，请求本地打包资源。
- 地图回归覆盖三个横屏尺寸、已保存建筑位置、详情面板、拖动与 180% 视角、正确经营入口、实际收集、满仓拒绝、旧存档导航和真实资料保护。
- 新农场对比未注入经营进度；全部建筑展示另用明确标注的测试存档。均为浏览器画面，非安卓真机实录。

未进行安卓真机帧率、内存、功耗、相机、语音、GPS、本地AI性能或系统覆盖安装测试。公开安装包、源码、签名和上一版更新检测结果见 GitHub Release。

## 限制

没有 Android 真机的模型性能/病害准确率、图库/相机/离线语音、定位精度或系统覆盖安装验证。模型是通用图文模型，不是经本应用专项验证的农学或兽医学确诊工具。临时媒体、附件说明和未保存的完成结果只保留在本次应用运行中；冷启后仅恢复文字草稿，结果需另存案例或主动导出。导出文字草稿为 JSON 备份/外部查看，本版没有草稿导入入口。

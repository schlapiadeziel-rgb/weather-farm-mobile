# v0.6.0 验证范围

Android versionName 0.6.0、versionCode 7；Game version 2 和原存档键保持，既有游戏备份可继续使用。公开 APK 沿用固定签名，私钥不进入源码或安装包。

## 规则与界面

- 198 项 TypeScript 测试，包含新增 14 项只读看板派生规则：计时边界、锁定田地、无效/缺失时间、共享库存订单、货款已收、稳定导航目标及输入不变。
- 看板按时间计算作物、动物、工坊和售出状态，不将 growth/progress 当成成熟依据；订单分别比较当前库存，不预留或自动消费货物。仓库空间来自同一份游戏库存。
- 看板独立浏览器检查覆盖 640×360、844×390、1280×720、390×844：统计、零就绪状态、计时跨界、导航、44 px 按钮、内部滚动、Escape/Tab、inert、恢复焦点和游戏原文不变。
- 工坊 14 组浏览器检查：缺料精确导航、新请求只定位/滚动一次、计时刷新保留手动选择、未建工坊不自动扣钱，满仓显示具体缺格且腾空间后只收一次；640×360 配方与队列分开滚动，桌面保持原有双栏。
- 订单、仓储与探索的专项检查：缺少数量、44 px 来源按钮、导航回调不消费库存、onChange=false 保留导出备份提示、void 回调兼容、初始卡车/货船及各子页定位。

- 最终 App 集成 9 组通过：三种横屏顶栏无溢出、44 px 看板入口、12 田中心全部命中；五类跳转与六类材料来源准确且不消费资源；时间刷新保留工坊手动选择，收动物产物后只开投喂面板而不自动喂食。
- 注入仅游戏存档键的 QuotaExceededError 后，连续两次补给仍明确显示未保存与备份提示；内存更新，磁盘存档保持原值。游戏导航没有写入真实农场、病例或需求键。
- 最后两组专项验证同页看板返回路边摊，货品、数量、单价草稿完整保留；手动页签不被计时重置，新的请求可准确切页。奶牛口粮入口精确到牛饲料配方，无额外资源消费。
- 生产构建完成 13 组经营、持久化、六个小镇服务和定位回归，0 pageerror；包含粗定位确认、手动坐标严格校验、晚到回调隔离与错误地区缓存隔离。
- Android Java、5 项更新 JUnit 和最终 APK 构建通过。本地固定签名 APK 的签名/证书、未改变应用载荷、版本/包名/横屏、ARM64 原生插件及 16 KB ZIP/ELF 对齐通过；公开 APK 和源码逐文件核验写入 GitHub 发布说明。

# v0.25.0 小镇画面升级

乡间杂货铺、林荫咖啡馆、河畔旅舍和列车换上为本项目生成的原创插画，分别保留青绿、陶红、淡紫的建筑辨识色。新增瓦片、木结构、窗台花箱、货篮与车厢材质；小镇背景采用柔和山丘、草地纹理、石子路和复用的主地图树木。

四张透明 WebP 合计 545,468 字节，均随安装包提供；没有复制第三方游戏素材。建筑和列车为静态插画，本轮没有加入列车行驶或轮子动画。图片失败时独立回退原矢量，树木也有矢量后备。

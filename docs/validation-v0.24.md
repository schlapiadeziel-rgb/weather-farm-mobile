# v0.24.0 验证范围

本轮只改进牧场与地图装饰动物美术、畜舍底景，不更改游戏经济、动物状态机、布局或存档结构；真实农场服务独立保留。

- TypeScript、最终生产构建与 331 项已有规则测试通过。
- 43 组最终生产 App 检查：10 组牧场美术/交互、7 组镜头、9 组地块操作、17 组地图回归，全部基于相同最终构建。
- 美术检查使用隔离存档，覆盖 640×360、844×390、1280×720；5 张透明 WebP 均为 640×640，可正确解码，6 个畜舍保持旧版外框范围，无页面横向溢出。比较基线由已校验的公开 v0.23.0 APK 提取。
- 五种动物逐个实际投喂，分别只扣 1 份对应饲料；推进测试时钟后，每种只收取 1 份正确产物。满仓拒绝收集，不丢产物、不产生假成功反馈。
- 模拟全部动物图片失败和单独奶牛图片失败，分别回退 SVG，其他物种不受影响；地图装饰动物也回退，投喂照常可用。
- 空畜舍购买山羊扣除实际价格并显示对应插画；减少动态效果关闭整体呼吸；底景无焦点目标、不拦截指针。阻断外部 HTTPS 后，图片仍从本地资源加载。
- 镜头/地图回归覆盖尺寸改变、详情开合、拖动、双指与 180% 视角、地标和快捷入口、旧存档导航及四个真实资料保护字段。地块检查包含播种/收获、局部反馈、存档失败和容量限制。
- 文档新农场对比没有注入等级或库存；五种动物合照另用明确标注的等级20测试存档。均为浏览器画面，非安卓真机实录。

未进行安卓真机帧率、内存、功耗、相机、语音、GPS、本地AI性能或系统覆盖安装测试。公开安装包、源码、签名和上一版更新检测结果见 GitHub Release。

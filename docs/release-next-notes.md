# 田野来信·新版 v0.30.0 · 订单补货返回

卡车、货船订单的“查看来源”现在保留原订单：从缺货商品进入工坊、再查原料，可逐层返回配方，最后一键回到原订单。自动恢复配送类型、定位卡片，并标记“当前备货订单”。

- 时钟与库存刷新不会反复滚动或抢焦点。
- 原订单已完成或更换时回到对应订单板，不误选替代订单。
- 普通导航与结束补货清除路径；导航不消耗库存、不发奖励。

[画面与验证](https://github.com/schlapiadeziel-rgb/weather-farm-mobile/blob/v0.30.0/docs/order-supply-return.md)

355项规则测试、生产构建及新增24组浏览器检查通过。覆盖三个横屏尺寸、默认动画和减少动态效果、配方逐层返回、换单与真实收获交付。

**已安装v0.29.0“田野来信·新版”可直接更新。** 本版沿用相同独立包名和固定签名，保留已有资料。v0.28及更早的旧包名应用首次迁入时，按[迁移指南](https://github.com/schlapiadeziel-rgb/weather-farm-mobile/blob/v0.30.0/docs/parallel-installation.md)分别导出／导入。

ARM64，Android6.0+，横屏。未实测安卓真机帧率、功耗或系统安装器中的覆盖安装。

原有小镇补货22组、页面按需加载27组、物品来源33组回归检查均通过；本轮合计106组浏览器检查，页面错误0。

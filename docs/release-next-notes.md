# 田野来信·新版 v0.33.0 · 中期经营与进度保留

本版包含 v0.32 的中期经营、触控与早期节奏优化，并修复工坊连产完成后收空队列会重复引导的问题。

- 第一轮经营完成后增加中期引导，帮助扩仓或开新田、工坊连产和稳定交付；可收起，全部完成后不再显示。提示只定位目标，操作和奖励仍由玩家实际完成。
- 同一座工坊成功排过两份制作后保留连产完成记录。收取、取消等待任务、加速、重启和备份往返均不会让这一步回退。旧存档从仍在队列中的任务补记，已收空的旧历史需要再次连排两份。
- 农田、牧场与经营面板的关键按钮对齐 44px 触控高度并补充读屏说明，保留键盘焦点环和减少动态效果设置。
- 100、125、150 三档扩仓材料各需每种 1 份，金币档位不变；9 级前订单每行不超过一次收获、配方或养殖收取。
- 保留 v0.31 的库存搜索与快捷上架、第一轮引导、轻量时钟刷新及游戏内更新。

沿用 v0.29 之后的独立包名和固定签名。已安装“田野来信·新版”的玩家，在游戏左上角菜单→检查更新→下载→安装更新，最后在安卓系统页面确认。旧包名应用首次迁入仍按迁移指南导出、导入资料。

ARM64，Android6.0+，横屏；未实测安卓真机帧率、功耗或系统安装器中的覆盖安装。

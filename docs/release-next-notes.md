# 田野来信·新版 v0.31.0 · 经营体验升级

这一版统一优化新手上手、库存查找与上架、时钟计算和游戏内更新提示。

- 新手经营卡按真实收获、养殖产物收取、订单交付推进，考虑成熟时间、满仓、缺种、饲料与等级；可收起，完成后不再显示。提示只定位目标，操作和奖励仍由玩家实际完成。
- 库存支持名称搜索、筒仓／谷仓过滤、数量排序。商品可直接“去上架”，预选准确物品、数量1和标准价，核对后手动上架。
- 时钟刷新仅复制变化的田地／畜栏，经济操作继续使用独立副本。云端代码基准耗时降低约62%–87%，此结果不代表真机帧率或功耗。
- 更新页明确v0.29及之后可在游戏里直接更新，保留当前资料；仅从旧包名首次迁入时需要导入备份。

[画面与验证](https://github.com/schlapiadeziel-rgb/weather-farm-mobile/blob/v0.31.0/docs/quality-pass-v0.31.md)

379项规则测试、生产构建、154组浏览器检查通过；默认动画下另完成15项连续操作复查。

沿用v0.29／v0.30的独立包名和固定签名。已安装“田野来信·新版”的玩家，在游戏左上角菜单→检查更新→下载→安装更新，最后在安卓系统页面确认。

ARM64，Android6.0+，横屏；未实测安卓真机帧率、功耗或系统安装器中的覆盖安装。

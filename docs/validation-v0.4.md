# v0.4.0 验证范围

本版在 v0.3.0 单机经营和真实农场服务基础上加入游戏内更新、镜头控制、工坊排队管理及游戏存档备份。Android versionCode 5，versionName 0.4.0。

## 已通过

- 168 项 TypeScript 测试。新增版本数值比较、draft/不完整资源过滤、同仓库与重定向来源、精确 SHA-256 文件匹配、取消/超时/限流/离线失败；工坊槽位价格、上限、仅等待任务取消、全额原料退回、跨仓满容量原子失败、串行时间提前；旧存档迁移、损坏原文保护、备份白名单、格式拒绝与 round-trip。
- 原生更新规则 5 项 JUnit 测试及 Java 编译，覆盖发布 URL、HTTPS 重定向、大小/版本/长度、哈希格式与签名集合。发布 CI 也运行原生单测。
- 13 组完整游戏/小镇回归：播种收成、饲料和产物、订单奖惩、补给/仓容、路边摊仅一次收款、探索等级、六个真实服务与模型中心、本机持久化、新位置/粗定位/坐标、晚到定位回调、错误地区缓存隔离。
- 工坊浏览器 16 组：槽位扣费、取消精确退款、确认前不扣、Esc/Tab/隔离/焦点、加速与收成、原料来源导航、9 槽滚动、满仓防扣、等待跨入生产与生产跨入成熟的确认保护。
- 镜头 18 组独立及主游戏检查：100%–180% 边界、鼠标/单指平移、CDP 双指 pinch、点击不吞、拖动不误收获、尺寸变化不露空白、HUD 不跟随缩放、建筑导航和小镇滚动互不影响、减少动态效果。
- 更新 UI 12 项模拟原生桥浏览器检查：用户触发下载、重复点击、进度、取消及晚到回调、关闭清监听、签名不一致、安装前保存、安装来源设置后二次启动；页面只声明「打开系统安装器」，不声明安装已成功。网页明确 APK 只适用于 Android，远程说明按纯文本显示。
- 根组件实际导出 JSON、取消与确认恢复、重载保留进度；存储配额失败不会伪报保存成功，唯一坏档不能覆盖，安装前写盘失败会阻止安装器；三个横屏尺寸（844×390、640×360、1280×720）五个游戏页不撑高文档，顶部更新入口可见。没有浏览器 pageerror。

Android APK 构建、固定 RSA 证书、签名验证、ZIP 16 KB 对齐与原生 ELF 16 KB 段对齐已通过本地检查；发布工作流要求与成功 CI 源码提交一致，逐项比对重签 APK 的应用内容，只允许签名元数据变化。公共 APK/源码/校验文件发布后再下载核验。

## 实际限制

没有 Android 真机安装器验证，桌面原生桥模拟不能证明设备的系统授权或覆盖安装完成。定位检查是浏览器 fresh fix 和原生规则/编译，未验证实地 GPS。AI 无专项病害准确率或 Android 真机性能测试，继续使用 v0.2 的引擎验证和风险提示。离线持久化与 JSON 备份不等于账号云同步。

从 v0.4.0 起公开包使用固定签名；更早的开发包可能不能覆盖。更新器拒绝签名不一致，不自动卸载，不清数据；旧版本没有游戏导出功能时，应保留仍需进度的旧版。私钥不进入仓库或公开资产。

# 农场游戏参考与本项目调整方向

研究日期：2026-10-09。本文实际读取公开官网、发行方商店介绍及官方图片，并对照当前项目的 `docs/planting.png`。这是页面与截图研究，没有安装或游玩这四款游戏；宣传截图不能证明完整首跑流程。下面分别标明已观察内容和本项目设计建议。仅参考玩法结构与界面原则，不使用对方代码、角色、地图、图标或图片作为本项目资产。

## 1. 《星露谷物语》：让农场本身成为主画面

已读取并成功返回 HTTP 200：

- [ConcernedApe 官方主页](https://www.stardewvalley.net/)
- [官方 About 介绍](https://www.stardewvalley.net/about/)
- [官方农场截图](https://www.stardewvalley.net/wp-content/uploads/2018/12/1_1screenshot15.png)

官网明确描述从祖父留下的旧农场、旧工具和少量金币开始，逐步种植、养殖、制作工具，并与小镇居民建立关系。农场发展与社区修复提供持续目标。

实际查看的截图是俯视像素场景：木屋与道路、整齐分块的田地、不同生长阶段和颜色的作物、果树、鸡与牛同时出现在同一场景。可耕作空间、农舍和通行路线的关系清楚，农场有生活感。该图没有展示新手任务步骤，因此不据此声称其首跑如何操作。

**用于本项目：** 玩家打开应用先进入自己的农场。保持房屋、田地、动物、小镇道路之间的空间关系，给一小块已有作物的田地和少量金币作为起点。真实问诊、天气、资讯和交易参考可以放进镇上建筑；农场成长目标仍由种植和经营驱动。

## 2. Hay Day《卡通农场》：轻触操作与短经营循环

已读取并成功返回 HTTP 200：

- [Supercell 官方游戏页](https://supercell.com/en/games/hayday/)
- [Supercell 发布的 Google Play 介绍](https://play.google.com/store/apps/details?id=com.supercell.hayday&hl=en)
- [官方横屏手机截图](https://supercell.com/images/32e8c9bae8508f7e03d245e466a206ff/Hay_Day_iPhone_image_V3.png)

发行方介绍证实的循环是种植与收获、留种再种、饲喂动物获得产物、加工食物、通过货车订单和路边商店销售、赚取金币再扩建。官方明确说作物不会因缺雨死亡，这是该游戏的休闲规则，不能解释为现实农学结论。

实际查看的横屏图中，农场占据绝大多数面积，等级在左上角、货币在右上角，快捷入口贴在边缘。订单板、货车、烤炉、房屋、围栏动物与作物是场景中的具体物件。田地旁的工具和可辨认的成熟作物传达操作机会，而不是先展示一整页统计表。

**用于本项目：** 成熟作物轻触就能收获，空地轻触出现种子选择，缺水作物给水滴提示和明确的浇水入口。金币、经验和产物就地反馈；完整健康、水分和成长数值放到主动打开的详情。用订单板串联“收获→交货→奖励→扩建”，首次几分钟内完成一次闭环。

**用于本项目：** 保持“小镇是经营去向”的结构。订单板明确展示缺哪种产物、库存是否足够、交货得到什么；能交付的订单显示就绪状态。面包坊、饲料房、仓库和农技站各自有明确用途，让建筑承担可理解的动作入口，不仅用于装饰。

## 4. Farming Simulator：把复杂知识拆为当前作业

已读取并成功返回 HTTP 200：

- [GIANTS Software 官方游戏介绍](https://www.farming-simulator.com/about.php?lang=en&country=us&platform=pcdigital)
- [Farming Simulator Academy 官方教程目录](https://www.farming-simulator.com/newsArticle.php?news_id=280&lang=en&country=us)

官方介绍覆盖播种、施肥、除草、耕地、收获、养殖、生产链和农场商店，并有天气事件和季节系统。Academy 面向初学者，将基础、设置与 HUD、首台机器、季节、地块、播种和收获等内容拆为逐项教程。它给本项目的价值是分解作业、把知识放在需要它的时刻。不能仅凭教程目录断言游戏内完整新手流程。

官方媒体页可以读取，但此次尝试的两张缩略图请求返回 HTTP 403，没有查看到图片；本文不记录未经观察的作业 HUD 或视觉细节。

**用于本项目：** 真实农场作业建议应给出一句可行动的解释，再提供详情入口；气象站展示带地区、时间与来源的真实天气。v0.3 游戏采用库存和倒计时经营规则，真实天气不直接改变游戏产量。学习内容按播种、灌溉、养殖和收获组织，避免初次进农场就要求阅读长篇农技说明。

## 对当前横屏原型的具体落地建议

这些是本项目的设计建议，不是对上述游戏现有功能的声明。研究开始时的 v0.2 参考截图把左侧导航、右侧常驻数值面板与中央田地并列，农场面积和第一步操作受到挤压；当时 README 以“真实农场工作台”描述首页。这些观察促成了本版游戏首页和小镇入口的调整。

### 第一优先级：打开就是可玩农场

1. 默认路由进入种植场景，保留上次农场进度；天气定位、模型下载或真实农场资料填写都不能阻塞进入游戏。
2. 场景占据横屏主体，边角只保留货币、等级、天气概况、背包与任务等少数入口。作物详情改为主动打开的小面板，不默认占据固定大块屏幕。
3. 地块以成长、成熟、缺水等视觉状态告诉玩家能做什么。选中时显示动作名称与结果；空地选种、成熟收获、缺水浇水的规则前后一致。
4. 收获有短动作、产物出现、金币或库存变动反馈。田地、动物和加工建筑的状态让玩家知道下一步，而不只靠侧栏文字。

### 第二优先级：用三个小任务教会循环

首轮建议是“收获一块已成熟萝卜→在空地种一块作物并浇水→向订单板交付萝卜”。任务来自真实游戏状态，完成操作才推进，不能仅因为打开面板就算完成。每步突出一个目标，奖励一次清楚的变化；完成后让玩家自由继续。未解锁的加工、养殖和扩建按可见目标逐步开放。

这是建议的新手序列，没有声称上述四款游戏采用完全相同的首跑安排。

### 第三优先级：将已有实际农技服务放进小镇

| 场景建筑 | 可复用的已有功能 | 进入时的明确身份 |
| --- | --- | --- |
| 农技站 / 兽医站 | 田间问诊、照片观察、本地模型设置、历史案例 | 真实农场服务，先填写真实对象和观察，不自动使用游戏健康值 |
| 气象站 | GPS / 手动选地区、预报、天气来源与获取时间 | 区域天气，区分模型数据、游戏天气效果和地块模拟水分 |
| 集市 | 游戏订单与产物出售；独立入口打开实际行情、订单和成本记录 | 游戏金币订单与真实报价、真实经营记录分别标明 |
| 乡村书屋 / 公告栏 | 官方资讯、季节指导、农技科普 | 显示发布者、日期、适用地区和原文链接 |
| 农场日志屋 | 游戏日记；独立入口打开本机实测和作业待办 | 游戏经历与真实采样、作业记录各自保留原有时间与单位 |

建筑可以增加亲切的引导角色，但真实问诊结果必须来自实际观察和已加载模型，官方资讯必须来自实际来源；角色对白不能伪装为专家确诊。真实功能可以始终直接访问，不应因游戏等级或金币不足而锁住。

### 天气和定位如何服务游戏

- 启动先玩，再在气象站设置地区。手动城市选择应作为稳定入口；GPS 成功与失败都给出明确结果，失败不弹出无法继续的流程。
- 所选城市、坐标来源和天气时点要可见。示例城市必须标明“示例”，不能伪称已定位到用户。
- 本版天气用于小镇里的真实农场服务，游戏倒计时与产量独立计算。真实待办建议继续使用独立的数据时效检查。
- 天气刷新失败时游戏仍可继续；使用缓存、默认游戏天气或暂停新的外部天气影响必须明确展示状态。不要把固定假天气包装为实时定位结果。

## 调整后的体验验收

1. 首次打开可以直接看见成熟作物和第一项简短任务，无需先填写工作台表单。
2. 玩家在一屏内理解空地、成熟、缺水分别如何操作；收获后清楚看见库存或货币变化。
3. 一轮种植与交货有明确回报，并引出下一项养殖、加工或扩建目标。
4. 点击小镇建筑能够打开对应真实服务，返回后继续原来的游戏位置与进度。
5. 定位权限被拒、GPS 超时或天气断网时，农场仍可玩，所用地区和天气状态不误导玩家。

本研究只修改本文。官方参考图片仅在临时目录查看，没有加入本项目或替换原创场景资产。

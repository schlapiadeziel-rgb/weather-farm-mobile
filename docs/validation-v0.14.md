# v0.14.0 验证范围

331 项 TypeScript 规则测试通过，其中新增 7 项操作反馈检查。版本配置为 Android versionName `0.14.0`、versionCode `15`。本版增加农田／牧场的短暂操作结果汇总与工坊收取后的手动再做一批；Game version 2、既有存档键、经济数值、配方、产量和计时规则保持。真实农场助手继续使用独立导航和数据。

## 本次操作汇总

`createFarmActionFeedback` 接收操作前后游戏、动作、成功编号与保存结果，核对对应地块或畜栏确有该操作的状态转换。数量按实际成功编号去重，库存与经验使用操作前后的真实差值，不根据手势经过数量、选中作物或示例数据推测奖励；材料奖励同样取自实际库存。

场景顶部中央显示本次播种、收获、投喂或收取，最多 3 项明细，超出标明其余项数。新操作替换上一条，约 2.2 秒后消失；零变更、失败、取消或只完成计时的加速不新建成功汇总。写盘失败仍可显示本次内存操作结果，但标记“未保存”并保留导出备份提醒。

组件在相机世界之外，位于边角 HUD 下方，自己和所有子元素点击穿透。它不获取焦点或增加音触觉，使用 `aria-hidden` 避免重复朗读，既有共享操作提示继续提供可访问状态。减少动态效果时停用进出动画，仍按时移除。

## 规则验证

`npm test` 的 331 项 TypeScript 测试全部通过，新增 `tests/farmActionFeedback.test.ts` 的 7 项测试使用实际游戏规则操作生成输入，覆盖：

- 混合作物收获与确实获得的材料奖励，最多 3 项及其余数量。
- 实际经验差值，以及货仓满时没有获得材料奖励就不显示奖励。
- 种子不足的部分成功、重复编号及误传经过编号，不扩大成功数量。
- 零成功、资源失败、仅推进计时及动作不匹配时不产生成功汇总。
- 不同动物投喂的负数饲料消耗，不增加经验。
- 混合动物产物收取与实际材料奖励，分别保留物品明细。
- 冻结的操作前后游戏和调用方编号保持不变，返回明细不引用可变库存。

这些规则检查说明结果汇总的来源与边界，不替代最终 App 布局、交互或 Android 硬件验证。[v0.13.0 完整验证](validation-v0.13.md) 保留为历史记录；其中测试总数、网页指纹与安装包检查不自动适用于本版。

## 工坊与数据边界

成功收取工坊成品后，界面保存刚收取配方，显示每批产量和原料当前库存／所需量。点击“再做一批”手动加入 1 批，继续使用原制作规则扣料和排队；缺料、生产位满或等级不足时禁用并给原因。空闲生产位可选配方；满仓成品保留并提供前往仓库。刚收取记录不写入存档，切换工坊、外部配方定位或离开页面后清除，不自动补单。

制作、收取、建造及钻石操作从最新已接受游戏状态执行，计时操作使用提交时刻；钻石确认再次核对对象和最新报价，变化后要求重新确认。已有原料、容量、等级、串行生产、退款与钻石定价规则保持。

全屏地图、边角等级与货币、菜单和工具、待收建筑导航、来客、小镇与布置继续保留。游戏操作不读取真实观察、实测或位置来计算产量，也不将游戏库存、模拟需求和报价用于真实问诊或经营结论。

## 动效边界

工坊补做的成功动效由已经接受的制作结果触发，按钮本身与焦点保持，装饰图形不拥有交互。经验环与滚动数字读取真实游戏值，辅助阅读立即给出实际值；减少动态效果时使用静态状态。页面圆形展开使用支持的 View Transition API；助手返回保留原入口位置。旧版 WebView 或减少动态效果设置下直接切页。导航准备同步执行，页面提交按最新请求决定，避免过时捕获恢复旧页面；不保存转场或动画状态。

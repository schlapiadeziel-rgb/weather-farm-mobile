# v0.11.0 验证范围

Android versionName 0.11.0、versionCode 12。游戏 Game version 2 与既有存档键保持；新增可选迁移的 layout 字段。真实农场服务仍在独立助手界面，布局只属于游戏。

## 规则与存档

- 295 项 TypeScript 测试通过，布局共有 17 项专项检查：固定地形、边界、贴边与碰撞、三地标与六免费装饰、不可变输入、规范顺序、未知字段/访问器/稀疏数组等异常输入、旧存档与备份迁移、恢复副本保护、真实资料键隔离、普通经营及小镇动作保留布局。
- 保存布局只改变 layout 与有上限的游戏日记；使用最新运行中的游戏保留作物、加工、小镇、库存、金币和钻石。编辑基线已过时则拒绝覆盖；取消与未保存的草稿不写入游戏备份。
- 实际画面检查发现地标地面未碰田地，但屋顶可能进入田块。新增艺术边界与中央田地的检查，保留三个原图默认位置；house(700,450) 等遮田落点拒绝，合法外围、六装饰和旧备份行为保留。艺术边界不从存档读取。

## 边界

只有一套启用布局；三个地标是功能区域整体，不是逐台移动 22 类机器或逐块移动田地。透视美术外轮廓和地面占位不同，允许相邻摆件的自然遮挡；没有购买升级、多布局槽、撤销历史、联网社区或跨玩家交易。

没有安卓真机触控、系统文件选择、相机/图库、离线语音、GPS 精度、本地模型性能或系统覆盖安装验证。通用图文模型没有该应用农学/兽医学专项准确率证明。游戏布局、商品、模拟需求和报酬不用于真实生产或经营判断。

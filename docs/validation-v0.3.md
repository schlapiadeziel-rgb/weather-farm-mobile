# v0.3.0 验证记录

本轮将游戏改为库存、加工与订单循环，并保留系统定位修复和真实农场服务。

- `npm test`：132/132 通过，覆盖库存容量、计时、串行生产、加速、订单、NPC 售卖、果园/鱼矿/蜂箱、存档迁移及异常存档、天气、真实数据解析和问诊规则。
- Chromium 横屏实际交互：播种/收获、饲喂/产物、交货、补给/扩容、NPC 三分钟售卖和单次收款、探索等级保护、六座小镇建筑、工作台记录和模型中心，均通过。1280×720 与 844×390 检查没有页面错误或横向溢出。
- 全部 57 个配方以隔离等级/金币/仓储夹具完成实际备料、建造、入队和收取，全部通过；没有直接注入中间原料，来源为当前补给、动物、果园、鱼塘、蜂箱、矿场与递归加工 API。工具不足时由实际收获奖励取得。此项不代表从零到最高级的完整平衡体验。
- 工坊独立检查：15 项交互通过，包括原料预扣、两个任务串行、槽位限制、钻石成本确认与取消、加速后后续前移、收取/释放槽位、购买及等级锁。
- 高等级经济界面：船运补单、苹果四轮含一次照料与砍除、蜂箱、捕鱼、铁铲与炸药采矿及成就单次领取等 8 条链路，通过。使用隔离测试存档和可控时钟；未将夹具截图作为真实农场数据或正常解锁截图。订单、仓库及探索面板可独立滚动，顶部工具栏保持在屏幕内。
- 定位网页检查：新位置、精度保存、6 公里粗定位确认、严格手填坐标、晚返回的位置不能覆盖手选城市、切换地区立即清旧天气及重启仍隔离旧缓存，通过。缓存测试使用明确测试夹具，不作为真实气象事实。
- 异常 JSON 的原始恢复副本保留；选中扩建畜栏后重开不白屏，真实待办仍保留。
- 原创斜角地图：四个建筑的触屏入口及 Enter 键通过；844×390 播种面板主操作可见，页面没有错误。
- 最终 Android ARM64 同步构建通过：v0.3.0 / code 4 / minSDK 23 / sensorLandscape；APK 签名、16 KB ZIP/ELF 对齐、原生定位与 AI 插件、随包许可及不包含模型权重的检查通过。已移除 Google 定位插件依赖。
- GitHub 发布使用相同提交的成功 Android CI 构建，附源码和 SHA-256；公开下载包检查在发布后进行。

官方来源及完整范围见 [Hay Day 系统范围表](hayday-feature-scope.md)。本版采用独立平衡值；船单、钓鱼及 NPC 交易是简化的本地玩法，不代表全部官方内容或真人联网。

没有进行安卓真机 GPS、专业病害准确率或联机规模验证。网页模拟定位、可控时钟和本机 NPC 不作为真实设备或多人验证；模型专项验证沿用 [v0.2 记录](validation-v0.2.md)。

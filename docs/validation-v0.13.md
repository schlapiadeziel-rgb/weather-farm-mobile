# v0.13.0 验证范围

324 项规则测试与 68 组最终生产 App 检查通过；原创美术另完成独立渲染和几何检查。本版不改变 Game version 2、既有存档键、经济数值或真实农场助手的数据边界。

## 建筑待收与存档

待收提示从实际生产队列、畜栏和当前时间只读计算，不保存另一份计数。工坊按完成但未收取的生产批次计数，牧场按已有产物的畜栏计数；点击提示或建筑，导航到首个待收机器的队列或畜栏。满仓时保留待收提示，实际收取仍由原经营规则核对容量。

324 项 TypeScript 测试全部通过，新增 7 项待收专项：空队列及空畜栏不提示、精确完成时间与过时进度字段、实际收取后计数与目标切换、饲料三份产出只算一批、动物收取后提示消失、满仓保留产物与待收状态、已保存地标移动后的坐标、未放置地标隐藏及输入不可变。其余存档、交易、小镇、布局、定位与真实服务规则继续通过全量测试。

## 原创美术

- 12 种作物分别渲染 5 个阶段，共 60 个样本；另检查 5 种动物及小尺寸缩略图。所有样本处于原有 120×112 坐标范围内，未出现浏览器页面错误。
- 景观前后使用同一 1200×700 画布；四条建筑入口交互路径逐字节相同，农舍、工坊、牧场的实际 SVG 几何边界与基线相同，SVG 标识符无重复。
- 正常状态能显示轻微动态；减少动态效果时停用，整理农场期间暂停。作物、动物阶段与状态含义、地标锚点和存档位置不变。

美术检查说明渲染、尺寸和动画开关，不代表手机帧率、耗电或低端设备性能基准。

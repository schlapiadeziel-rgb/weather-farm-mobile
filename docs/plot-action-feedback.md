# 地块原地操作提示

2026-10-24，纳入 v0.16.0 的地块反馈优化。

实际成功播种或收获后，对应地块短暂显示“已播种”或“已收获”，1.6 秒后移除。连续操作仅标记确实变化的地块，部分成功时不为失败地块显示成功。提示位于地图地块中，随镜头移动，反向旋转保持文字方向；提示及其所有子元素均不拦截触控，不改变地块尺寸。

提示不添加经验、库存或额外奖励，不替代顶部实际数量汇总，也不将本次总奖励分摊成虚构的每格数字。保存失败时本地提示明确改为“未保存”，顶部汇总仍保留相同说明。装饰元素对读屏隐藏，沿用现有可朗读操作结果，避免重复播报。

同一地块再次成功操作会替换对应提示并重新计时。切页、打开菜单或其他相关弹窗、恢复和重置游戏均清除临时提示；状态不写入游戏存档。减少动态效果时静态显示，仍按时移除。

## 验证

TypeScript/Vite 生产构建及 331 项规则测试通过。Chromium 中 9 组实际 App 检查通过，无页面异常：

- 640×360、844×390、1280×720：混合作物连续收获只标记两个实际成功地块，尺寸稳定，提示触控穿透；1.6 秒后消失而顶部汇总按自身时间继续显示；四个真实农场资料键逐字节保持不变。
- 原料不足的连续播种只标记实际用种成功的地块。
- 取消播种与空地收获没有成功提示，也不改变游戏。
- 本机存储失败显示“未保存”，仅内存中种植成功，磁盘游戏存档不变。
- 同格先收获再播种正确替换提示并重置计时。
- 打开菜单与切换页面清除旧提示。
- 减少动态效果不播放进入动画，但仍按期移除。

# v0.2.0 验证范围

本版以农场主的真实工作为主，模型输出仅用于辅助排查。结构过关不等于农学或兽医学准确率已获验证。

- 自动化测试覆盖天气来源与单位、真实日期/时刻、缓存失败、官方页面实际快照、订单与成本口径、本机记录、问诊结构/中英文危险承诺/类别错配，以及种植养殖玩法。GitHub Actions 构建会运行完整测试后同步界面并构建 APK。
- Chromium 实际操作验证：待办完成/撤销、实测录入与 JSON 备份、否定句与紧急症状、无模型保存观察、历史快照、模型中心、真实官方缓存的七项报价、确认订单提示、新闻搜索、带日期的科普、作物和动物收获。1280×720 与 844×390 横屏检查无页面错误或横向溢出。
- 原生 ARM64 构建、APK v1/v2 签名验证、`sensorLandscape`、Android 6.0 最低版本、关闭自动备份和 16KB 库/包对齐已检查。APK 中包含 llama.cpp/libmtmd 推理库、同源 GBNF 与第三方许可证；不包含模型权重。
- Linux x86_64 使用固定引擎与实际下载且 SHA-256 匹配的 Qwen3.5 2B 权重运行了中文文字和原创游戏插画图文推理。无约束输出存在数组类型错误、JSON 闭合错误，应用拒绝；施加同源 GBNF 后两例均生成可解析结构。
- 试跑还暴露作物案例中错误的“联系兽医”及搬移病株建议，已经加入类别校验与回归测试，保留独立检查提醒。图文试跑使用插画，不能作为病害识别准确率测试。

尚未完成安卓真机性能、相机/语音兼容性矩阵、真实病害数据集、农学与兽医学专项评估。Linux 的推理时间与内存占用不能当作手机指标。较大模型参数量也不能替代专业验证。

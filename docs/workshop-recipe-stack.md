# 工坊配方叠卡

2026-10-24，主分支界面优化。v0.14.0 已发布 APK 不包含此改动；本次没有新建发布标签或替换旧安装包。

未解锁配方默认收成一叠卡片，显示真实数量与下一份配方的解锁等级。点击可展开或收起，当前可用配方排在前面。切换机器时恢复收起；全部解锁后不显示空叠卡。

订单“查看来源”即使指向未解锁配方，也会展开并滚动到对应配方。收起会清除这次配方定位。查看配方不自动排产，不改变原料、金币、钻石、任务或存档格式；生产仍由原有规则检查。

按钮支持 Enter 和空格、保持焦点，并提供 aria-expanded 与指向实际卡片的 aria-controls。展开有短暂淡入和位移动画，减少动态效果模式下关闭动画。

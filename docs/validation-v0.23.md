# v0.23.0 验证范围

本轮只调整地图美术及地块材质，没有改动游戏规则、点击区域、布局定义或存档结构；真实农场服务独立保留。

- TypeScript 与最终生产构建、331 项已有规则测试通过。
- 41 组最终生产 App 界面检查通过：8 组美术专项、7 组镜头/尺寸变化、9 组地块反馈和实际农场操作、17 组地图入口与旧存档导航回归。
- 美术专项覆盖 640×360、844×390、1280×720 三种横屏；4 张 WebP 原始尺寸均为 1254×1254，透明角与图像中心像素解码正常；21 棵树、3 座主要建筑加载新插画。
- 三种尺寸的地块外框、地标点击路径和布局地面范围，均与实际公开 v0.22.0 APK 中网页资源的渲染结果逐项一致。对比基线从公开 APK 解出，没有用新代码伪造旧版基线。
- 模拟四张插画全部请求失败、单张风车图片请求失败，独立回退原有 SVG；键盘访问工坊/探索仍可用。阻断外部 HTTPS 后，本地美术照常加载。
- 布置编辑器使用同一套插画，移动农舍一格、保存、刷新后位置仍正确；没有改变库存、金币或真实资料。减少动态效果下，新插画可见，场景动画关闭。
- 镜头回归覆盖拖动、160% 缩放、详情面板开合、尺寸变化、边界覆盖、双指缩放与中断手势；地图回归覆盖 180% 视角、地标/快捷入口、旧存档与独立农场助手。
- 地块操作检查覆盖真正种植/收获、部分成功、容量或存档失败、局部反馈与减少动态效果。隔离存档仅用于自动检查，不代表自然游戏进度。
- 文档的升级前后截图另由同一固定起始时钟的新农场生成，没有注入等级或库存；为浏览器画面，不是安卓真机实录。

没有测试安卓真机帧率、内存占用、功耗、GPU 表现、相机、语音、GPS、本地 AI 性能或系统覆盖安装。未从浏览器结果推断真机性能。公开文件、签名及上一版更新检测结果见 GitHub Release。

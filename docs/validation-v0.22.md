# v0.22.0 验证范围

改进游戏内工坊补货导航，不更改经济规则、存档结构或真实农场服务。

- TypeScript、生产构建及 331 项已有规则测试。
- 10 组最终生产 App 检查，采用隔离测试存档：640×360、844×390、1280×720 三种横屏下的曲奇→红糖→农田→红糖→曲奇路径；牧场鸡蛋补货返回；探索果园苹果补货返回；主动关闭；进入真实助手清除且保留四个真实资料保护字段；刷新不保留导航；重复点击不叠加返回层且支持键盘操作；地图补货入口替换金币区域，关闭后恢复。
- 三种尺寸检查返回按钮处于视口内、没有页面横向溢出；导航前后库存、金币与队列不变；检查页面运行异常。
- 工坊原料齐备筛选的 8 组已有 App 检查重新运行，覆盖实际扣料、空结果补货、工坊切换与队列容量限制。
- 未对恢复备份和重置后的导航清除执行专项 UI 测试；这两个入口已接入清除处理。
- 隔离测试数据不代表自然游戏进度。尚未进行安卓真机触摸、辅助功能读屏、GPS、相机、语音、模型性能或系统覆盖安装测试。
- 发布后核验公开安装包、源码、固定签名、网页资源一致性及上一版更新检测；结果见 GitHub Release。

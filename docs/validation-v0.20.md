# v0.20.0 验证范围

本轮只改进游戏内访客收购清单，不修改经济规则、存档结构或真实农场服务。

- TypeScript 与生产构建通过；331 项已有规则测试通过。
- Playwright 加载实际 FarmVisitors 源组件，使用隔离库存测试数据，验证作物留种计入需求、准确缺口、备齐边界、补货入口、确认前不出售、送别不显示备货、动物产品不留种、超额库存进度封顶。
- 640×360、844×390、1280×720 三种横屏尺寸下对话框在视口内、没有页面横向溢出；无页面异常。
- 组件专项不等于完整 App 端到端验证。没有执行安卓真机触摸、辅助功能读屏、GPS、相机、语音、模型性能或系统安装测试。
- 公开安装包、签名、源码与网页资源一致性将在发布后核验；结果见 GitHub Release。

# 路边摊预览与仓库连续操作

v0.18.0 上架前显示商品、数量、预计货款与扣除这批后剩余库存；预计货款不立即进入钱包，仍需等待本机 NPC 购买并主动收款。作物这批会用完库存时提醒留种，不阻止玩家主动卖出。

界面数量限制为 1–min(10, 当前商品库存) 的整数，单价为 1–商品基础价格三倍的整数；无库存、货位满、数量或单价不合法时显示原因并禁用上架。切换商品重置数量为 1，并恢复新商品基础单价；不静默把非法输入改成另一笔交易。引擎仍会检查最新库存和六个货位。

上架、收款、补给购买、扩容与扩地使用最新已接受的状态；收款按实际操作时刻判断。扩容和扩地核对本次界面报价，报价变化时拒绝旧请求并提醒重新查看。上层延迟返回新属性、本地切页重绘时不会把已接受状态退回旧值。保存失败明确提示备份，内存交易与磁盘保存分开。

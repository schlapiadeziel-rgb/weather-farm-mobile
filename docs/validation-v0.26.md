# v0.26.0 验证范围

本轮改进六种前期生产设施美术及其小型地面阴影，不修改经济、解锁、生产队列或存档规则；真实农场服务独立保留。

- TypeScript、最终生产构建与 331 项已有规则测试通过。
- 28 组最终生产 App 检查：10 组工坊美术与经营交互、8 组配方筛选、10 组原料来源返回导航，使用相同最终构建。
- 在 640×360、844×390、1280×720 检查六张本地透明 WebP 解码；另外 16 类建筑仍显示原矢量。全部 22 类卡片及美术外框与已校验公开 v0.25.0 APK 逐项比较相同，无页面横向溢出。
- 隔离测试存档逐个实际制作鸡饲料、面包、奶油、红糖、爆米花和培根煎蛋，核对准确扣料与 30/120/240 秒计时；主动收取分别得到 3 份饲料或 1 份对应产品，连点不重复结算。
- 所有六张图片失败时逐个回退原矢量，仍可制作；单独乳品坊图片失败不影响其他素材，切换到制糖坊建造预览正确显示。未达等级的四种设施继续变淡并禁止建造。
- 乳品坊、制糖坊、爆米花锅和烧烤架通过实际按钮建造，分别准确扣除 180、220、260、320 游戏金币。选择或加载插画不扣费。满仓时六个已完成批次保留，收取按钮禁用，不产生假的补做成功卡片。
- 减少动态效果下插画无动画，不增加焦点或指针目标；独立助手切换与重载保留机器队列和四个真实资料保护字段。美术检查阻断外部 HTTPS，插画从安装包本地路径提供。
- 配方与来源回归覆盖原料齐备筛选、实际制作后的即时刷新、未解锁配方、满队列、缺料来源、多层返回、果园返回、重复点击、键盘操作、暂存导航清理、三个横屏尺寸及真实资料保护。
- 新农场对比未注入经营进度；六种设施合照另用明确标注的等级20测试存档。均为浏览器画面，非安卓真机实录。

未进行安卓真机帧率、内存、功耗、相机、语音、GPS、本地AI性能或系统覆盖安装测试。公开安装包、源码、签名和上一版更新检测结果见 GitHub Release。

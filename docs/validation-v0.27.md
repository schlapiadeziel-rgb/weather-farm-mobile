# v0.27.0 验证范围

本轮新增六种中期生产设施插画，不修改游戏经济、解锁、生产队列或存档规则；真实农场服务独立保留。

- TypeScript、最终生产构建与 331 项已有规则测试通过。
- 28 组最终生产 App 检查：10 组工坊美术与经营交互、8 组配方筛选、10 组原料来源返回导航，使用相同最终构建。
- 在 640×360、844×390、1280×720 检查六张新增及六张前期透明插画的解码；另外十类建筑保留原矢量。全部 22 类卡片及美术外框与已校验公开 v0.26.0 APK 逐项比较相同，无页面横向溢出。
- 隔离测试存档逐个实际制作胡萝卜馅饼、棉布、棉衬衫、奶油蛋糕、胡萝卜汁和原味冰淇淋，核对准确扣料与 4/5/6/7 分钟时长。主动收取只增加 1 份对应产品，连点不重复结算；棉布同时作为原料和产物，核对消费后的净库存。
- 全部十二张工坊插画失败时分别回退原矢量，仍可制作馅饼；单独织布机图片失败不影响其他十一张，切换到缝纫间建造预览显示正确。
- 六种新增插画设施通过实际按钮建造，分别准确扣除 380、480、560、640、720、800 游戏金币。选择或加载图片不扣费；未达等级时继续变淡并禁止建造。
- 满仓时六个已完成批次保留，收取按钮禁用，不产生假的补做成功卡片。减少动态效果下工坊美术无动画，不增加焦点或指针目标。
- 独立助手切换与重载保留机器队列和四个真实资料保护字段。美术检查阻断外部 HTTPS，插画从本地打包路径提供。
- 配方与来源回归覆盖原料齐备筛选、实际制作后的即时刷新、未解锁配方、满队列、缺料来源、多层返回、果园返回、重复点击、键盘操作、暂存导航清理、三个横屏尺寸和真实资料保护。
- 新农场待解锁预览未注入进度；六种已建设施前后对比使用相同、明确标注的等级20测试存档。均为浏览器画面，非安卓真机实录。

未进行安卓真机帧率、内存、功耗、相机、语音、GPS、本地AI性能或系统覆盖安装测试。公开安装包、源码、签名和上一版更新检测结果见 GitHub Release。

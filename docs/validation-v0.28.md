# v0.28.0 验证范围

本轮补齐十类后期生产设施插画，全部 22 类工坊使用本地插画，并保留逐个回退原矢量；不修改经济、解锁、生产队列或存档规则。

- TypeScript、最终生产构建与 331 项已有规则测试通过。
- 28 组最终生产 App 检查：10 组工坊美术与经营交互、8 组配方筛选、10 组原料来源返回导航，使用相同最终构建。
- 在 640×360、844×390、1280×720 检查全部 22 张工坊图片解码；边角 alpha 不超过 1/255，至少 5% 像素完全透明，保留边缘抗锯齿。全部 22 类卡片及美术外框与已校验公开 v0.27.0 APK 逐项比较相同，无页面横向溢出。
- 隔离测试存档逐个实际制作浆果酱、铁锭、手镯、浓缩咖啡、蜂蜡、太妃糖、酱油、鱼寿司、田园沙拉和番茄汤，核对准确扣料与 3/4/5/6/7/8/10 分钟时长。主动收取每项只增加 1 份对应产品，连点不重复结算；铁锭和酱油同时作为原料与产物，核对消费后的净库存。
- 全部 22 张工坊图片失败时分别回退原矢量，仍可制作果酱；单独首饰工坊失败不影响其他 21 张，切换到咖啡亭建造预览显示正确。
- 十类新增插画设施通过实际按钮建造，分别扣除对应的 900、1000、1200、1400、1100、1500、1600、1750、1900、2050 游戏金币。选择或加载图片不扣费；未达 13–23 级相应门槛时变淡并禁止建造。
- 满仓时十个已完成批次保留，收取按钮禁用，不产生假的补做成功卡片。减少动态效果下美术静态显示，不增加焦点或指针目标。
- 独立助手切换与重载保留机器队列和四个真实资料保护字段。美术检查阻断外部 HTTPS，图片从本地打包路径加载。
- 配方与来源回归覆盖原料齐备筛选、制作后的即时刷新、未解锁配方、满队列、缺料来源、多层返回、果园返回、重复点击、键盘操作、暂存导航清理、三个横屏尺寸和真实资料保护。

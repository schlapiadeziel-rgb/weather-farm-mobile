# 田野来信 v0.7.0 · 现场观察草稿与本机 AI 恢复

这一版继续保留横屏农场和小镇服务，重点保护农场主尚未提交的现场资料。

- AI 诊所自动保存未完成的表单文字、实测勾选和语音核对状态。300 ms 自动保存，换页/退后台及时保存；写入失败单独提示，可先导出文字草稿。草稿不是已保存案例，不自动上传。
- 同次应用运行中切去工作台或游戏再回来，保留临时照片/关键帧、附件说明及完成结果；离开诊室会请求停止推理和语音，不自动恢复分析，也不会取消用户已启动的模型下载。
- 冷启动只恢复文字与勾选，不恢复原生媒体 ID、照片或模型结果。曾有附件时明确要求重选并补充说明，或由用户选择“本次仅用文字”后继续。
- 推理重试失败、停止或晚到输出不再吞掉上一份已完成快照；旧结果可保存/导出，并明确标注它不是本次失败或停止的输出。
- 模型出错且仍在内存中时，提供手动“卸载并重新加载”入口，防止只能在禁用按钮间来回尝试；不自动下载或推理。返回诊室会刷新实测记录，已选的较早记录也可查看和取消。
- 清空文字草稿需确认，保留案例、实测、游戏存档及当前附件；损坏草稿覆盖前保留恢复副本，无法备份时不覆盖旧内容。

214 项 TypeScript 测试、5 项原生更新 JUnit、诊室与经营/定位的浏览器验证范围见仓库文档。原生桥模拟用于验证 UI 与异步状态，不能替代 Android 真机模型、图库、语音或覆盖安装测试。

APK 沿用现有固定签名，支持 Android ARM64 6.0+。已安装 v0.4.0 及之后的固定签名版，可从顶部“更新”检查新版，最后在 Android 系统安装器确认。iPad/iPhone 无法安装 Android APK。模型仍需首次下载或导入。

本地模型用于辅助整理观察，没有经过该应用农学/兽医学专项验证的诊断准确率，不能替代专业现场检查。游戏为独立单机原型；游戏进度、真实农场资料、案例和草稿分别保存，清除应用数据/卸载可能删除本机资料。

附固定签名 APK、源码 ZIP 和 SHA256SUMS.txt。

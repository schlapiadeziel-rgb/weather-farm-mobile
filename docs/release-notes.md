# 田野来信 v0.4.0 · 游戏内更新与触屏优化

顶部与农场日记新增「游戏更新」：检查 GitHub 新版本和说明，用户点下载后显示进度，可取消、重试；Android 核对完整长度、SHA-256、包名、版本和签名后打开系统安装器。首次安装来源授权后返回继续安装，安装始终需要系统确认。公共 APK 从此版开始使用固定签名；签名不同会停止操作，不会卸载或清数据。

- 地图支持 100%–180% 缩放、双指缩放、单指拖动与复位；拖动不误收获，HUD 保持原位。新增麦田、风车、水纹和芦苇微动。
- 工坊可以扩充至 9 个生产位，取消未开始任务消耗 1 钻石并全额退原料；钻石操作明确确认，满仓或任务已开始会阻止操作。缺料可以直接去农田、牧场、探索或前置工坊。
- 农场日记可以导出和确认恢复游戏 JSON 备份；操作与退后台保存，减少频繁存储写入。损坏存档先保留恢复副本。
- 保留小镇真实天气、本机图文 AI、官方资讯、市场参考与农场工作室，保留系统 GPS、粗定位确认、手填坐标和旧地区天气隔离；回到前台可刷新过期天气，查询失败也可重试。

168 项 TypeScript 规则/数据测试、5 项原生更新边界测试、浏览器经营/备份/定位/镜头/更新状态检查、Android 编译与签名校验已通过。模拟原生桥测试不代表已完成真实 Android 跨版本安装验证。

仅支持 ARM64 Android 6.0+；模型需要首次下载或导入。网页和 iPad/iPhone 不能安装 Android APK。旧版开发签名可能不同；如果仍需要旧版的游戏进度，请保留旧版，先备份能导出的资料再决定迁移。普通同签名覆盖更新保留本机数据，卸载或清除数据仍会删除记录。

本版仍是独立单机农场原型，未实现 Hay Day 全部内容或玩家联机。真实 AI 辅助整理观察，农学/兽医学准确率及 Android 真机定位/性能尚未验证。

附固定签名安装包 `field-letter.apk`、源码 ZIP 与 `SHA256SUMS.txt`。

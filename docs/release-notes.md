# 田野来信 v0.10.0 · 独立农场助手与小镇经营

真实农场服务有了独立界面。游戏顶部点击“农场助手”，集中使用工作台、真实天气、AI 现场观察、农业资讯、市场参考和农事参考；点击“返回游戏”回到刚才的经营页面。

- 游戏画面保留经营导航、库存和货币；助手使用独立导航与浅色界面，不显示游戏钱包。切换时清除上一模式的短暂反馈。
- 天气与定位放在助手中。未确认真实位置时不展示示例城市的天气，游戏启动和游戏中的刷新计时不查询真实天气；手机定位、城市搜索、手填坐标、粗定位确认与地区缓存隔离保留。
- AI 问诊、农场记录、资讯和市场入口集中到助手。同次运行切换界面仍保留问诊文字、临时附件与完成结果；离开时停止推理和语音，忽略迟到结果。
- 游戏小镇加入原创列车、三类店铺与明确标注的本机模拟访客。主动迎接列车后，交付显示的游戏物品开始接待，计时结束手动领取金币、经验和声望；声望解锁咖啡馆与旅舍，可建造并升级接待容量。
- 到站、交货、领奖和建造均防重复；缺货不部分扣除，离线不自动领奖。旧存档自动添加初始小镇，游戏备份包含设施与访客，不更改真实农场资料。
- 更新六页新手手册；小横屏助手导航可滚动，入口和小镇操作使用至少 44px 点击目标。

278 项 TypeScript 测试、5 项原生更新 JUnit、16 组实际 App 集成与 13 组经营/定位回归通过。640×360、844×390、1280×720 布局及点击检查通过。详见 [v0.10.0 验证范围](https://github.com/schlapiadeziel-rgb/weather-farm-mobile/blob/v0.10.0/docs/validation-v0.10.md)。

APK 沿用现有固定签名，支持 Android ARM64 6.0+。v0.4.0 起的固定签名版本可通过应用更新入口检查新版，最后由 Android 系统安装器确认。模型需另行下载或导入；iPad/iPhone 无法安装 Android APK。

这是原创单机原型，尚未实现 Hay Day 的全部内容或多人系统。没有 Android 真机触控、相机、定位精度、本地模型性能或系统覆盖安装验证。本地模型没有该应用专项农学/兽医学诊断准确率证明，辅助观察不能替代现场专业检查；游戏收益不代表现实生产。

# 田野来信 v0.5.0 · 连续播种收获与农场手册

这一版让横屏农场更容易上手，继续保留服务真实农场主的小镇、定位修复和本机 AI。

- 田地新增浏览、连续播种、连续收获三种方式。选种后划过地块，预览高亮，松手一次完成；反复划过同一块只处理一次。种子或仓容不足会停止并保留已完成的部分，不消耗游戏金币或钻石。
- 多指、系统取消、失焦、弹窗或切换方式会取消笔划；旧合成点击不会误收获。浏览方式的普通轻点、拖动地图和双指缩放仍可用。
- 可选农场手册以五步图鉴介绍留种、养殖、工坊、订单和小镇。指引可跳转至对应区域，不强制弹出、不扣费，不把游戏库存和订单当成真实生产数据。
- 修复窄横屏的透明底部区域及相机按钮挡地块、3D 田地命中问题。640×360、844×390 和 1280×720 的 12 块地均可点。
- 小镇五个服务页面按需加载，减少开场脚本量；计时刷新保留未提交草稿，挂载不额外写入真实记录。
- 更新窗口同一进程关闭重开后可继续安装匹配的已校验包；安装来源设置返回后刷新权限，下载过程不会重置进度。安装前仍保存游戏并重新核对安装包与签名；缓存缺失或校验失败时提供重新下载。

184 项 TypeScript 数据/规则测试、5 项原生更新 JUnit、浏览器连续手势、新手手册、更新状态、经营和定位回归通过。完整 12 块田在测试存档中连续播种、成熟收获和重载验证通过；该测试使用明确的等级/解锁夹具，不代表自然升级过程的平衡测试。

APK 沿用 v0.4.0 的固定签名，支持 Android ARM64 6.0+。从已安装 v0.4.0 的游戏顶部「更新」检查此版；最后需要在 Android 系统安装器确认。未知来源设置、真实设备下载及跨版本覆盖安装尚未完成真机验证。模型需首次下载或导入；iPad/iPhone 不能安装 Android APK。

游戏是独立单机原型，未实现 Hay Day 全部内容或玩家联机。真实 AI 辅助整理线索，农学/兽医学准确率与 Android 真机定位/性能尚未验证。游戏进度与真实农场资料分别保存和备份。

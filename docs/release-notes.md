# 田野来信 v0.2.0 · 农场服务与本机 AI 试玩版

首页改为农场主的每日工作台，加入真实待办、采样记录、备份、田间观察与本机图文 AI，配合官方农业资讯和全国批发行情；模拟种植与养殖使用新的高清场景和作物、动物矢量画面。

- Qwen3.5 0.8B / 2B / 4B 三档本地模型，按设备内存推荐，固定版本 SHA-256 校验；首次需要手动下载或导入，模型不包含在 APK 中。
- 拍照、短视频关键帧、离线中文语音与文字输入，整理可能原因、补充检查及求助条件；保存本机案例和模型来源。
- 官方新闻展示发布日期与原文；行情保留报价日期、单位和全国统计范围，结合用户确认的当地订单和成本提供核查建议。
- 真实服务与游戏数值分离，天气/资讯失败和缓存状态明确。

安装包仅支持 ARM64 Android 6.0+，使用开发密钥签名；若旧版提示签名冲突，需先备份可导出的记录再卸载旧版，卸载会清除本机数据。模型建议至少 6 / 8 / 12 GB 内存，较大模型更慢且需要更多可用内存；离线语音需要 Android 12+ 和本机中文语音包。尚未完成安卓真机性能与农学/兽医学专项准确率验证，模型输出用于辅助排查，不能作为确诊或用药处方。

# 田野来信 v0.27.0 · 中期生产工坊美术升级

- 馅饼炉、织布机、缝纫间、蛋糕房、榨汁坊和冰淇淋机换上原创插画，强化炉台、布料、织布与缝纫结构、木制压榨机和冰淇淋桶的辨识度。
- 保留原来的建筑卡片、触控范围、解锁、建造、实际扣料、生产计时和手动收取流程。
- 六张新增本地透明 WebP 合计约 0.99 MB；连同上一版，共十二类工坊使用插画，其余十类保留原矢量。图片失败时独立回退。
- 新插画为静态，本轮没有设备运转动画；炉火、食物与布料等绘制细节不代表当前队列或库存。
- 真实天气、定位、本地AI、资讯、行情与记录继续保留在独立农场助手。

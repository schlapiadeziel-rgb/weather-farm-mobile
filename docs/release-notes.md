# 田野来信 v0.11.0 · 整理农场与完整地图

游戏顶部新增“整理农场”，可以预览自己的农场布置，保存后继续经营。

- 农场小屋、风车工坊和牧场畜舍三个地标区域可整体移动，动物、围栏、招牌和阴影随地标移动；中央耕地、河流、水塘和小镇保持原位。
- 新增六件原创免费装饰：两座花圃、两段绿篱和两段木栅。可摆放、微调或收回，不消耗游戏金币、钻石或库存。
- 支持拖动、点选落点、44px 方向按钮和键盘操作；未摆放装饰可用“摆到空地”放下后微调。地图检查固定区域、边界和地面占位，非法预览不能保存。
- 编辑只修改草稿。保存才应用，取消或 Escape 保留原布置；恢复初始布置也先预览。多指、失焦、指针中断不会提交尚未结束的移动。
- 保存使用最新游戏状态，不覆盖编辑期间已经成熟的作物、加工和小镇计时。旧存档及旧备份自动补入初始布局；新游戏备份包含布局。写盘失败会明确提示，本次布局仍保留在运行中的游戏里。
- 田块与场景使用同一地图比例，小屏和详情面板不会再把田块放大到摆件上；会遮住田地的非默认地标落点会被阻止。
- 地图镜头保留完整画布，原先被裁掉的边缘可以通过拖动查看。保留缩放、双指手势和复位，修复丢失捕获、失焦等中断后尾随点击可能误收获的问题。

真实天气、定位、本地 AI、资讯、行情和农场记录继续使用独立“农场助手”界面；游戏布置不用于现实农场规划或生产建议。

这仍是原创单机游戏原型，不是 Hay Day 的完整内容或多人系统。当前移动的是地标区域，尚不支持逐台移动 22 类机器、逐块移动田地、多布局槽或装饰购买升级。

295 项规则测试、5 项原生更新 JUnit、37 组最终布局/地图界面检查通过；已有牧场、助手和定位回归也通过。验证明细见 [v0.11.0 验证范围](https://github.com/schlapiadeziel-rgb/weather-farm-mobile/blob/v0.11.0/docs/validation-v0.11.md)。Android ARM64 6.0+，沿用 v0.4.0 起的固定签名。模型需另行下载或导入；iPad/iPhone 无法安装 Android APK。

未完成安卓真机触控、相机、语音、GPS 精度、本地模型性能或系统覆盖安装验证。本地通用模型没有经本应用农学/兽医学专项验证的诊断准确率。

附固定签名 APK、源码 ZIP 与 SHA256SUMS.txt。

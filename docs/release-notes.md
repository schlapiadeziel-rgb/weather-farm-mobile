# 田野来信 v0.13.0 · 场景细节与建筑待收导航

屋顶、树冠、水面、作物和动物增加原创材质与光影层次。工坊和牧场新增随建筑位置移动的待收提示，点一下即可找到有成品的机器或畜栏，减少来回查找。

- 屋顶瓦纹、木板与墙面、树冠高光、草地和水光、接地阴影更有层次；保持原有地标边界、道路和田地位置；成熟田地的收获标签改为更清晰的深棕文字。
- 麦穗、玉米颗粒与披叶、其他作物的叶片及果实更清晰；成熟地块的收获文字提高对比度。五种动物补充材质、眨眼和轻微甩尾。减少动态效果会停用动画，整理农场时暂停。
- 工坊显示完成但未收取的生产批次数，牧场显示已有产物的畜栏数。提示跟随保存后的建筑位置；点击提示或建筑，直接打开首个待收机器的队列或对应畜栏。没有待收时仍打开普通经营页面。
- 待收提示只导航，不自动收取、投喂或扣货。满仓时仍保留待收状态；真正收取继续核对容量。饲料一次产出三份时仍计为一批，不把件数冒充批次数。
- 沿用全屏农田/牧场、边角等级与货币、折叠经营菜单和工具、农场门口来客与小镇经营；真实天气、定位、本地 AI、资讯、行情和记录继续在独立“农场助手”内。
- Game version 2 与既有存档键保持，不新增待收计数存档；每次从实际生产队列、畜栏和当前时间计算。游戏状态、库存和模拟价格不参与现实问诊或经营建议。

这是参考农场经营核心循环的原创单机原型，尚未实现 Hay Day 的全部内容或联网系统；场景、作物和动物资产独立绘制。

324 项规则测试通过，其中新增 7 项建筑待收检查；68 组最终生产 App 检查通过，覆盖待收导航、三种横屏尺寸、拖动/缩放、旧存档与真实资料隔离、HUD/菜单、来客及美术。独立渲染另核对了 12 种作物的 60 个阶段样本、5 种动物、地标边界、交互路径和动画规则。本机 APK 构建、固定签名、完整网页载荷与 16 KB 对齐检查通过。验证范围见 [v0.13.0 验证范围](https://github.com/schlapiadeziel-rgb/weather-farm-mobile/blob/v0.13.0/docs/validation-v0.13.md)。

Android ARM64 6.0+，沿用 v0.4.0 起的固定签名；versionCode 为 14。模型需另行下载或导入；iPad/iPhone 无法安装 Android APK。

未完成安卓真机触控、相机、语音、GPS 精度、本地模型性能或系统覆盖安装验证。本地通用模型没有经本应用农学/兽医学专项验证的诊断准确率。

附固定签名 APK、源码 ZIP 与 SHA256SUMS.txt；公开文件的校验与更新兼容结果在实际发布核验后补入发布说明。

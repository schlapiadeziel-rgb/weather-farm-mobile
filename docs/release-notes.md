# 田野来信 v0.26.0 · 前期生产工坊美术升级

- 饲料坊、面包坊、乳品坊、制糖坊、爆米花锅和烧烤架换上原创插画，强化磨盘、炉灶、奶罐、铜锅和工具细节。
- 六种设施增加柔和接地层次，保留原来的建筑卡片、点击范围、解锁、建造、制作队列与手动收取流程。
- 六张本地透明 WebP 合计约 0.99 MB，失败时逐个回退原矢量；其余 16 类生产建筑继续使用原矢量。
- 新插画为静态，本轮没有新增设备运转动画；炉火、蒸汽等绘制细节不表示生产状态，队列提示仍跟随实际时间。
- 真实天气、定位、本地AI、资讯、行情与记录继续保留在独立农场助手。

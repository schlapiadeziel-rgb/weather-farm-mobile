# 田野来信 v0.21.0 · 工坊配方更好找

- 工坊显示原料齐备的配方数量，可一键只看已解锁且原料足够的配方。
- 加入队列后按实际库存更新筛选；多份配方共用原料，不会预留或自动生产。
- 没有匹配配方时可返回全部配方，继续查看缺料与补货入口。
- 切换工坊或从其他入口定位具体配方时恢复全部配方，避免筛选遮住目标。
- 生产位满时仍禁止加入队列；真实农场服务继续保留在独立农场助手。

包名 com.fieldletter.farm，版本 0.21.0 / code22，固定签名，ARM64，Android6.0+，横屏。

# 田野来信 v0.18.0 · 路边摊预览与仓库交易

上架前看清预计货款和剩余库存，连续操作也保留每次有效交易。

- 路边摊新增商品数量、预计货款与上架后库存预览；最后一份作物提醒留种，不自动卖出或收款。
- 非法数量/单价、无库存或六货位已满时禁用上架并说明原因；更换商品重置数量为1及该商品基础价格。
- 上架、收款、补给购买、扩容和扩地使用最新已接受状态；上层属性延迟、本地页签重绘时不覆盖之前的有效操作。
- 收款使用实际操作时刻，重复收同一笔会被拒绝。扩容或扩地报价变化后拒绝旧请求，不按旧页面扣下一档费用。
- 本机保存失败保留实际内存结果并提示备份，不宣称磁盘已保存。
- 保留订单备货筛选、地块反馈与镜头优化。真实天气、定位、本地AI、资讯、行情和记录继续在独立农场助手界面。

# 田野来信 v0.12.0 · 全屏农场与门口来客

农田与牧场改为全屏场景：去掉顶部横条、左侧分类栏和底部状态栏，把等级、货币与少量圆形入口放到边角。农场门口还新增四位原创邻居，主动迎接后再决定出售、送客或稍后处理。

- 左下“经营”打开农场菜单，集中八个经营入口及看板、布置、手册、更新、音效、重开六项工具；右下“助手”继续打开独立真实农场服务。其他经营页面保留各自的页面导航。
- 选中地块后才显示田地工具，默认收起；镜头按钮也按需展开。场景中的建筑入口、订单和经营状态继续可用。
- 界面组织参考了实际查看的 [Supercell 官方横屏截图](https://supercell.com/images/32e8c9bae8508f7e03d245e466a206ff/Hay_Day_iPhone_image_V3.png)；没有把公开静态图研究描述为完整游玩或最新版本逐项一致。

- 邮差阿穗、竹匠芦叔、邻居陶婶、画师小蓝轮流来访，每次只等一位；使用原创矢量人物入口，不占用或移动你的农场布置。
- 每位邻居提出一种商品、1–5 份的固定需求，只从已解锁且有富余的实际游戏库存中选择。收购作物、动物产物、加工品、水果和鱼肉；不收饲料、工具、建材、矿石或金属锭。
- 报价为基础游戏总价的 1.1 倍向上取整，另给 2 + 数量的经验。出售和送客都先确认，实际提交重新核对当前来客、库存与时间；作物售后须留下 2 份种子。
- 可以稍后再说。关闭窗口、切换农场助手或离线不会丢掉当前来客，也不会自动交易、换单或领奖。成交或送客后冷却 2 分钟，再主动接待下一位；送客不扣库存也不给奖励。
- 来客和冷却随游戏存档及备份保存。旧存档缺少来客时补入空门口；存在但损坏的来客状态会被拒绝。异常备份不替换当前游戏，损坏的本机存档保留原始恢复副本。

原有整理农场、种植、养殖、加工、小镇经营继续保留。真实天气、定位、本地 AI、资讯、行情和农场记录继续使用独立“农场助手”；模拟来客的需求与报价不用于现实经营建议。

这是原创单机游戏原型，尚未实现 Hay Day 的全部内容或联网系统。门口来客与小镇列车游客是独立玩法；四位邻居是本机 NPC，没有真人交易、每日访客配额或仓库部件奖励。

317 项规则测试、42 组最终 App 界面检查与 5 项原生更新 JUnit 通过；规则测试中新增 22 项来客检查。验证范围见 [v0.12.0 验证范围](https://github.com/schlapiadeziel-rgb/weather-farm-mobile/blob/v0.12.0/docs/validation-v0.12.md)。Android ARM64 6.0+，沿用 v0.4.0 起的固定签名。模型需另行下载或导入；iPad/iPhone 无法安装 Android APK。

未完成安卓真机触控、相机、语音、GPS 精度、本地模型性能或系统覆盖安装验证。本地通用模型没有经本应用农学/兽医学专项验证的诊断准确率。

附固定签名 APK、源码 ZIP 与 SHA256SUMS.txt。

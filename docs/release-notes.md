# 田野来信 v0.3.0 · 单机农场经营试玩版

默认进入可玩农田，参考 Hay Day 经营循环重做库存、加工与订单，保留小镇里的真实农场服务和定位修复。

- 播种用库存 1 份，成熟收获 2 份入筒仓；动物消耗饲料，产物入谷仓，收获不再直接换金币。
- 12 种作物、5 种动物、22 类机器、57 个配方；真实倒计时、离线进度、串行队列、收取和游戏钻石加速。
- 卡车与船订单、本机 NPC 路边摊、库存容量、升级仓库、扩地和扩建畜舍。
- 果园、钓鱼、矿山、蜂箱和成就；原创斜角农场地图，建筑可直接点击，含道路、水塘、围栏和作物动物。
- 真实天气、拍照/视频关键帧/离线语音、本机 Qwen3.5 图文 AI、农业新闻与实际订单成本记录仍从小镇建筑进入。
- Android 使用系统 GPS / 网络定位，支持无 Google Play 设备，显示精度和提供者；独立选址、手填坐标、同名地区核对与旧天气隔离。

本版是独立单机原型，尚未实现 Hay Day 全部内容、真实邻里、玩家交易、德比和联网活动；源码附有系统范围表。

仅支持 ARM64 Android 6.0+；模型需要首次下载或导入。尚未完成安卓真机定位/性能和病害准确率验证，真实 AI 用于辅助排查。开发签名可能与旧包不同；安装冲突时先导出可备份的真实记录再卸载旧版，卸载会清除本机数据。

附安装包、源码 ZIP 与 SHA256SUMS.txt。

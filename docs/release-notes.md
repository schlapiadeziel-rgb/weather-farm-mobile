# 田野来信 v0.25.0 · 小镇建筑与列车美术升级

- 乡间杂货铺、林荫咖啡馆、河畔旅舍换上原创插画，增加屋顶瓦片、木结构、花箱与货篮细节。
- 列车改为青绿与奶油色的原创插画，车厢、窗户和轮组更清晰；建筑与列车为静态，本轮没有新增行驶或轮子动画。
- 小镇背景补充柔和山丘、草地纹理、石子路与主地图同风格树木，保留原建筑按钮和列车外框。

# 田野来信 v0.16.0 · 地块原地反馈与镜头优化

连续播种、收获时，更容易辨认实际完成的地块；开合详情或改变屏幕尺寸时，镜头尽量保持正在观察的位置。

- 实际成功播种、收获的地块显示原地提示，约 1.6 秒后移除。只标记成功变化的地块，取消、零变化与失败不新建成功反馈；同格再次成功操作会替换提示并重新计时。
- 本机保存失败明确显示“未保存”；保留顶部实际数量汇总与可朗读操作结果。原地提示不挡触控、不改变地块大小，也不新增奖励或存档字段。减少动态效果时静态显示后移除。
- 打开菜单、相关弹窗、切换页面、恢复或重置游戏会清除临时地块提示。
- 镜头在详情面板开合、窗口尺寸变化时，按原中心对应的农场逻辑位置重算视角，并继续限制边界防止露白；复位仍回到中心 100%。
- 点回地图会收起临时缩放控件，同时保留本次点击；直接使用控件不提前关闭。Escape 收起后恢复焦点，复位按钮可读出当前缩放比例。
- 继续保留拖动与双指缩放后的误点击拦截，避免误收获或误进入建筑。
- 沿用上一版工坊配方叠卡、生产状态、读屏进度、手动再做一批和轻度队列吸附。真实天气、定位、本地 AI、资讯、行情与农场记录仍在独立“农场助手”界面。

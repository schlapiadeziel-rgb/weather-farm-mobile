# 田野来信 v0.8.0 · 问诊备份恢复

这一版继续保留横屏农场经营、小镇真实服务和既有定位修复，补齐现场资料的备份导入。

- 本机案例支持单个、旧版全部案例和新版 JSON 备份。选择文件先显示新增、重复、编号冲突及合并数量，再明确确认；完全重复跳过，有冲突的本机记录保留，其他新案例仍可加入。
- 超过 20 个案例或保存大小限制时阻止合并，不截断记录；本机资料异常、预览后存储改变或写入失败时明确提示。全部案例导出严格读取完整存储，避免把损坏内容误作空列表。
- 导入案例明确标注来源未核验；模型信息只是文件声明。模型原始输出重新执行结构与内容校验，紧急警讯按观察重新计算，不信任备份里序列化的结论。
- 文字草稿支持文件预览与确认替换，保留未完成原文与语音待核对状态；未写完的数量也能原样显示，提交时仍须有效整数。跨设备实测编号不自动关联，天气需重选；曾有图片时要求重新选择或明确仅用文字。
- 当前附件需先处理，恢复不会混入其他现场图片。文字变更、离开页面或取消后丢弃旧预览和晚到文件读取；导入不自动下载模型或开始推理，不修改已完成结果、农场实测记录或游戏进度。

239 项 TypeScript 测试以及浏览器和 Android 验证范围见 [v0.8.0 验证范围](validation-v0.8.md)。

APK 沿用现有固定签名，支持 Android ARM64 6.0+。已安装 v0.4.0 及之后的固定签名版，可从顶部“更新”检查新版，最后在 Android 系统安装器确认。iPad/iPhone 无法安装 Android APK。模型仍需首次下载或导入。

本地模型没有经过本应用农学或兽医学专项准确率验证，结果用于辅助整理观察，不能替代专业现场检查。案例备份只含文字与媒体说明，不含原照片、视频或音轨。清除应用数据或卸载可能删除本机资料，请保留导出的备份。

附固定签名 APK、源码 ZIP 和 SHA256SUMS.txt。

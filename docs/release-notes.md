# 田野来信 v0.14.0 · 操作反馈、工坊补做与联动动效

播种、收获、投喂和收取后，场景上方短暂显示本次实际变化。工坊成功收取成品后可手动再做一批，减少在队列和配方之间查找。

- 农田与牧场的单次、连续操作按实际成功结果汇总库存消耗、混合作物或动物产物、真实经验及取得的材料奖励；最多显示 3 项，其余显示项数。汇总约 2.2 秒消失，新操作替换旧记录，零变更、取消和失败不新建成功提示。
- 场景汇总不拦点击、不改变镜头或边角入口；减少动态效果时静态显示后消失。保留已有可朗读操作提示，写盘失败明确标记“未保存”并提醒导出备份，不把内存中的成果宣称为已保存。
- 工坊成功收取后显示刚收取配方、每批产量和原料的当前库存／所需量，主动点“再做一批”只加入 1 批。缺原料、生产位已满或等级未到时禁用并说明原因；空闲生产位可返回选配方，满仓成品保留并可前往仓库。
- 刚收取配方仅属于本次工坊会话，切换工坊、外部配方定位或离开后清除，不自动补单。制作、收取、建造及钻石操作使用最新已接受的游戏状态；计时操作按提交时刻核对，钻石对象或报价变化时需重新确认。
- “再做一批”在实际排队成功后收圆、画勾并散开小粒子；只播放装饰动效，不等待动画才扣原料。按钮保留点击区域与焦点，失败或初次显示不播放成功动画。
- 等级徽章增加真实经验进度环，等级、金币与钻石在数值变化时短暂滚动，辅助阅读立即使用当前实际数值。跨级会按新等级重置经验环，不插入虚拟奖励。
- 支持的浏览器与 Android WebView 可从点击位置圆形展开页面，从农场进入助手后再返回会向原入口收回；快速切页以最后一次选择为准。减少动态效果或不支持转场时直接切换。
- 沿用全屏农田／牧场、边角等级与货币、折叠菜单和工具、建筑待收导航、农场门口来客、小镇经营与农场布置。真实天气、定位、本地 AI、资讯、行情和记录继续在独立“农场助手”内。
- Game version 2、既有存档键、经济数值、生产配方、产量和计时规则保持；本次汇总与刚收取配方不新增存档字段。游戏库存、需求、报价和生产计时不参与真实问诊或经营建议。

这是参考农场经营核心循环的原创单机原型，尚未实现 Hay Day 的全部内容或联网系统；场景、作物和动物资产独立绘制。

331 项 TypeScript 规则测试与 103 组实际 App 检查通过，其中新增 7 项操作反馈规则测试。界面检查包含 90 组功能回归和最后样式调整后的 13 组动效复核，具体构建指纹和范围见验证记录。验证范围及实际执行结果见 [v0.14.0 验证范围](https://github.com/schlapiadeziel-rgb/weather-farm-mobile/blob/v0.14.0/docs/validation-v0.14.md)。[v0.13.0 完整验证](https://github.com/schlapiadeziel-rgb/weather-farm-mobile/blob/v0.13.0/docs/validation-v0.13.md) 保留为历史记录，不将历史检查数计作本版通过。

Android ARM64 6.0+，版本配置为 `0.14.0` / versionCode `15`。公开 APK 沿用 v0.4.0 起的固定签名；模型需另行下载或导入，iPad/iPhone 无法安装 Android APK。

未完成安卓真机触控、相机、语音、GPS 精度、本地模型性能或系统覆盖安装验证。本地通用模型没有经本应用农学/兽医学专项验证的诊断准确率。

# 田野来信 v0.6.0 · 农场看板与材料来源

这一版把收成、加工和交货串得更清楚，继续保留小镇里的真实天气、定位、本机 AI、资讯和真实农场资料。

- 新增可主动打开的农场看板：五类就绪状态、最近完成的倒计时和双仓容量；点击可以去对应地块、畜舍、工坊、订单类别或路边摊。入口只导航，不自动收取、投喂、制作或交货。
- 游戏地图栏显示已就绪数量。订单按每份需求分别核对库存，多单可能需要同一批货，交货后会重新计算。
- 订单列出每项还缺多少，点击来源可查看对应作物、动物、配方、果园、鱼塘、矿山和蜂箱。加工缺料也可精确导航，计时刷新不会反复跳回配方；同页经看板回到路边摊时保留未提交的货品、数量与单价。
- 修复工坊、订单、仓库、探索页面缺失操作提示，以及成功提示盖住存档失败警告的问题；连续写盘失败仍会提醒导出备份。
- 低矮横屏的工坊改为可切换的配方/队列视图，保留至少 44 px 操作按钮；谷仓不足时显示缺少的空间。动物产物收取后打开畜舍面板，方便安排下一轮投喂；修正畜舍就绪勾标的倾斜样式。

198 项 TypeScript 测试、5 项原生更新 JUnit，以及看板、材料导航、写盘失败和经营/定位浏览器检查见仓库验证文档。高等级测试存档用于覆盖已解锁功能，不代表自然升级或经济平衡验证。

APK 沿用 v0.4.0/v0.5.0 的固定签名，支持 Android ARM64 6.0+。已装 v0.4.0 或 v0.5.0 可从游戏顶部「更新」检查新版，最后在 Android 系统安装器确认；跨版本覆盖安装尚未完成真机验证。模型需首次下载或导入；iPad/iPhone 不能安装 Android APK。

游戏仍为原创单机原型，未实现 Hay Day 全部内容或玩家联机。真实 AI 用于辅助整理线索，农学/兽医学准确率与 Android 真机定位/模型性能尚未验证。游戏进度与真实农场资料分别保存和备份。

附固定签名 APK、源码 ZIP 和 SHA256SUMS.txt。

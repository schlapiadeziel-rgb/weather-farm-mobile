# 田野来信 v0.19.0 · 果园状态与探索收取

看清果园当前能做什么，并确保连续收取与领奖不覆盖前一次成果。

- 果园增加待采摘、结果中、待照料、待清理的实际数量，计时到期只更新状态，不自动采摘。
- 果实、鱼肉、蜂蜜放不下时显示需要腾出的对应仓库空位并禁用收取，保留待收状态，提示支持读屏。
- 果园、蜂箱、钓鱼、矿山和成就操作使用最新已接受状态及实际提交时刻；延迟属性或切换页签不会回退前一笔操作。
- 旧任务、未到期任务、重复领奖由原规则拒绝；采矿因仓库容量失败不会损失工具。
- 保存失败保留实际内存结果并提醒备份，不宣称磁盘已保存。
- 沿用路边摊预览、订单备货、地块反馈和镜头优化；真实天气、定位、本地AI、资讯、行情与记录仍在独立农场助手。

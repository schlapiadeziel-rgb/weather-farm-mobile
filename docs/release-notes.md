# 田野来信 v0.15.0 · 工坊配方叠卡与生产状态

工坊默认收起未解锁配方，优先显示目前可用的内容。生产队列增加实际状态数量与读屏进度，横屏操作更清楚。

- 未解锁配方以叠卡显示真实数量和下一个解锁等级，点击展开或收起；支持键盘，保持焦点，减少动态效果时关闭进入动画。全部解锁后不显示空叠卡。
- 订单“查看来源”可自动展开并定位锁定配方，查看不会自动制作、扣除原料或交货。切换机器恢复收起。
- 当前工坊按真实时间显示“待收取、制作中、排队中”数量。空队列不显示数量；满仓成品保留空间需求提示与禁用的收取按钮。
- 进度条提供读屏名称、0–100 实际进度与等待说明，未开始的产品进度为 0；完成后仍需主动收取。
- 宽屏横向队列使用原生轻度滚动吸附；较矮横屏继续使用纵向网格，减少动态效果时关闭进度插值过渡。
- 保留 v0.14.0 的实际操作反馈、手动再做一批、完成按钮动效、真实经验与货币联动、触点圆形转场。
- 真实天气、定位、本地 AI、资讯、行情与实际农场记录仍在独立“农场助手”界面；本版未修改这些服务与存档结构。

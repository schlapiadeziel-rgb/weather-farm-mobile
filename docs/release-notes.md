# 田野来信 v0.9.0 · 连续照料牧场与触控优化

这一版重点改善横屏农场经营的操作节奏与画面反馈。

- 牧场加入浏览、连续投喂、连续收集工具。划过畜舍会显示预览，松手后统一处理；同一畜舍去重，按动物使用各自口粮。投喂、收集是两个独立动作，不自动花钻石或购买动物。
- 饲料不足或仓满时停止后续操作，保留已经完成的部分并明确提示；浏览时可以滚动畜舍，操作时多指、切页、失焦、弹窗或取消手势不会误提交。键盘与辅助激活也支持操作。
- 动物产物就绪时有金色层次和勾选提示，成功投喂/收集出现短暂反馈；减少动态效果模式保留静态提示。
- 作物和动物加速使用钻石前显示确认框，支持取消、键盘焦点和 ESC。确认时重新检查目标批次、倒计时和实际费用；已结束、目标变化或费用超过确认数量时阻止扣除。加速后仍需主动收取。
- 小屏点击有成品的工坊，直接显示生产队列；从原料来源进入时仍显示指定配方。
- 修正小屏横屏中重开按钮和牧场工具栏被遮挡的问题，顶部可见按钮采用 44px 点击目标；最小横屏侧栏为保留全部入口使用较紧凑布局。

游戏仍为原创单机原型；小镇真实农场服务、位置设置与游戏进度分别保存。游戏产量、金币和钻石不参与现实建议。

267 项 TypeScript 测试、5 项原生更新 JUnit、30 组实际 App 交互与 13 组经营/定位回归通过。规则与界面验证见 [v0.9.0 验证范围](validation-v0.9.md)。APK 沿用现有固定签名，支持 Android ARM64 6.0+。已安装 v0.4.0 及之后固定签名版，可从游戏顶部更新入口检查新版，最后由 Android 系统安装器确认。

没有 Android 真机触控、图库/相机、定位精度、本地模型或系统覆盖安装验证。本地模型没有该应用专项农学/兽医学诊断准确率证明，辅助观察不能替代现场专业检查。模型需首次下载或导入；iPad/iPhone 无法安装 Android APK。

附固定签名 APK、源码 ZIP 和 SHA256SUMS.txt。

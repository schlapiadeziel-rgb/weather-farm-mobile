# 田野来信 v0.17.0 · 订单备货与连续交货

更快找到已备齐的订单，清楚知道每单还差哪些货物，并修复快速连续操作使用旧状态的问题。

- 增加当前可交货订单数量、“只看可交货”和每单真实备货进度；按已满足数量要求的商品种类计算，超额库存不重复计数。筛选保留原序号，不预留库存或自动交货。
- 各订单共用库存，交掉一单后重新检查其余订单；筛选为空可返回全部，真正无订单时仍由原规则接一批新订单。
- 交货、更换和接单使用最新已接受的状态及提交时刻；上层延迟返回新属性时，本地筛选重绘也不会退回旧库存。旧单重复操作被原规则拒绝。
- 保存失败保留本次内存结果并明确提示未保存与备份，不会据旧磁盘状态重复消耗原料。
- 保留缺货商品直达种植、牧场、工坊等来源；键盘筛选保留焦点，进度支持读屏，减少动态效果时不播放进度过渡。
- 沿用地块原地反馈、镜头中心保持、工坊叠卡和手动补做。真实天气、定位、本地 AI、资讯、行情和记录仍在独立“农场助手”界面。

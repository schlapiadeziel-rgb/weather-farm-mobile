# 田野来信 v0.24.0 · 牧场动物美术升级

- 鸡、奶牛、猪、绵羊和山羊换上原创插画，增加羽毛、皮毛与柔和光影；地图装饰奶牛与鸡同步更新。
- 畜舍增加草地、木栏和接地层次，保留原来的编号、投喂、倒计时、待收集提示和点击范围。
- 五张本地透明 WebP 合计约 0.35 MB，减少动态效果时关闭呼吸动画，图片失败时独立回退原矢量。
- 动物是静态插画配整体轻微呼吸，没有新增独立逐帧眨眼或尾部动画。
- 真实天气、定位、本地AI、资讯、行情与记录继续保留在独立农场助手。

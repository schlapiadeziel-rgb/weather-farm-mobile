# 田野来信 v0.23.0 · 农场美术升级

- 换上原创树木、农舍、畜舍与风车插画，增强树冠、瓦片、木材和石基的光影层次。
- 草地增加草丛、小花、石子与明暗变化，远景丘陵更柔和；田垄、道路和水塘增加材质与水深细节。
- 四张透明 WebP 素材随安装包离线提供，资源加载失败时使用原有 SVG 图形。插画风车帆叶为静态美术；水中鱼影仅作装饰。
- 沿用原有世界坐标、地块、地标点击区域与存档结构，不增加常驻界面入口。
- 真实天气、定位、本地AI、资讯、行情与农场记录继续保留在独立农场助手。

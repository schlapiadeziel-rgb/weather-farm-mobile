# v0.12.0 农场界面参考

观察日期：2026-10-20。实际读取 [Supercell 的 Hay Day 官网](https://supercell.com/en/games/hayday/) 与该页引用的 [横屏手机截图](https://supercell.com/images/32e8c9bae8508f7e03d245e466a206ff/Hay_Day_iPhone_image_V3.png)，两者返回 HTTP 200；下载后查看了图片。研究对象为公开静态截图，没有安装或游玩 Hay Day，也未据此确认当前版本每个按钮和交互流程。

## 实际看到的画面

| 位置或区域 | 官方截图中观察到的内容 | 本项目的调整 |
| --- | --- | --- |
| 整个屏幕 | 农场场景延伸到屏幕四边，没有顶部品牌横条、左侧有背景的分类栏或底部状态栏。 | 农田和牧场使用全屏场景；取消这些常驻页面框架。 |
| 左上与右上 | 左上为等级星；右上为金币和钻石两行数值。 | 左上放原创等级/经验徽章，右上放游戏金币和钻石。 |

| 场景中央 | 田地、订单板、货车、建筑和人物占据中央；没有常驻的播种/收获工具牌。 | 田地工具在选中地块或进入连续操作后出现，默认折叠；地图缩放按钮按需展开。中央继续用于场景与田地操作。 |
| 美术 | 建筑、人物、植被有更丰富的颜色、阴影、材质与体积感。 | 本版先修正界面占位；原创矢量场景与人物仍需继续改善美术和动画，不能称画面质量已经相同。 |

## 本版的具体操作

农田与牧场左下的“经营”打开“农场菜单”。“经营入口”有农田、牧场、工坊、订单、探索、小镇、仓库、农场日记；“工具与设置”有看板、整理农场、手册、检查更新、音效与重新开始。重开仍先显示已有确认，不因点菜单直接重置。

轻点地块查看或操作，再按需要展开田地工具；持续播种或收获时保留当前方式入口。地图仍支持拖动和双指缩放；没有手势时，也可以展开镜头按钮进行缩放或复位。游戏建筑与订单入口继续保留。

真实天气、定位、本地 AI、资讯、行情与农场记录属于本项目的独立农场助手。农田/牧场从右下“助手”进入，其他游戏经营页面保留顶部入口。它们不使用游戏库存或模拟访客报价作为现实判断依据。

## 范围

工坊、订单、小镇等经营页面仍有各自的页面布局，本版没有把全部功能变成场景中的逐台建筑。四位门口邻居为本机模拟角色，不是真人社交。界面参考采用布局和信息组织原则；没有把 Hay Day 的图片、角色、图标、地图或代码加入游戏资产，也不宣称与其完整内容或最新界面逐项一致。

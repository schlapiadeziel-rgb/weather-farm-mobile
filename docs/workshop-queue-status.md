# 工坊队列状态与滚动

2026-10-24，纳入 v0.15.0 的工坊界面优化。

生产队列按任务的实际开始和完成时间区分“待收取、制作中、排队中”，显示当前工坊各状态的任务数。空队列不显示数量提示。已完成但仓库放不下的任务仍属于待收取，保留腾出空间提示与禁用的收取按钮。

卡片使用边框、序号和现有文字同时区分状态；制作进度条提供名称、0–100 数值和读屏说明。排队中的进度为 0，说明尚未开始。计时沿用 App 正常采样，不另开装饰计时器，不自动收取或加速。

高度超过 550 像素时，横向队列启用原生 proximity 滚动吸附；较矮横屏沿用纵向卡片网格，不强加横向吸附。减少动态效果模式保留真实进度值并关闭进度插值过渡。生产、仓库、钻石和存档规则未变。

# 游戏内更新

从 v0.4.0 起，顶部下载图标与农场日记提供「游戏更新」。启动时安静检查一次；用户也可以手动检查。只读取本项目的 GitHub Releases，包含标明为测试版的 prerelease；不会自动下载 APK。

Android 用户点下载后可查看进度或取消。下载使用 GitHub 的 HTTPS 发布地址，限制大小、超时与重定向，核对 SHA-256、完整文件长度、应用包名、更高 versionCode、版本名和现有应用签名。安装前再次核验缓存，并保存当前游戏。首次允许「安装未知应用」后，需要返回游戏点「继续安装」；系统安装器要求用户确认，游戏无法静默替换自己。

普通覆盖更新保留游戏、模型及真实记录。签名不同会停止下载安装，不会自动卸载、删除记录或绕过检查。网页、iPad、iPhone 无法安装 Android APK，更新页面提供发布页链接。

## 发布签名

v0.4.0 公共 APK 开始使用固定 RSA 签名。公开证书摘要保存在 `android-signing-certificate.sha256`；发布工作流只允许该证书。v0.3.0 及以前的开发签名可能不同，首次换用新版可能需要手动迁移。保留旧版本并备份可导出的真实记录；旧版本不支持游戏进度导出时，不要卸载仍需保留进度的应用。

私钥没有提交到仓库、源码包或安装包。当前维护环境将现有私钥和密码文件放在 `/workspace/.private/weather-farm-signing/`，目录 0700、文件 0600。维护者应通过自己的安全备份保管该目录；丢失密钥不能用新密钥覆盖现有应用，脚本不会重新生成密钥。

维护者可使用已有密钥签署成功 CI 构建的 APK：

```bash
python scripts/sign-update-apk.py original.apk field-letter.apk \
  --signing-dir /path/to/private-signing-directory --sdk /path/to/android-sdk
```

脚本验证签名，并逐项比较 ZIP 中的应用内容；仅签名元数据允许改变。保留 Java 和 SDK 的正常代理及证书配置。

GitHub Actions 配置 `ANDROID_KEYSTORE_BASE64`、`ANDROID_KEYSTORE_PASSWORD`、`ANDROID_KEY_ALIAS`、`ANDROID_KEY_PASSWORD` 这四项仓库秘密后，可以直接输出固定签名包。没有秘密时，构建工作流仍输出开发试玩包，但发布工作流拒绝将其作为公共更新包。

当前 GitHub 连接不能设置仓库秘密（API 返回 403），因此此版使用本地固定签名。维护者把已签名的公开 APK 和原成功构建的源码提交号 `source-commit.txt` 放在临时交付分支，发布工作流接收其完整提交 SHA `signed_apk_ref`。工作流核对原构建成功且提交号匹配版本标签，逐项比较已签名 APK 与该构建内容，并核对固定证书，再发布 APK、源码和 SHA256SUMS。发布后删除临时交付分支；其中只有公开安装包，没有私钥。

## 存档与验证边界

农场日记支持游戏 JSON 导出和导入，导入前显示替换确认。真实记录在农场工作室单独导出；位置和原媒体不进入游戏备份。卸载、清除应用数据仍会删除本机数据，分享选择器打开不表示目标位置已保存成功。

版本/来源/校验解析、并发与界面状态、原生 URL/边界规则、编译和包签名已验证。尚未在真实 Android 设备完成安装来源设置、下载取消及跨版本覆盖安装验证；桌面模拟的原生桥测试不能替代真机安装器验证。

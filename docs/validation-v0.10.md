# v0.10.0 验证范围

Android versionName 0.10.0、versionCode 11。游戏 Game version 2 与既有存档键保持；新增的小镇字段兼容缺少该字段的旧存档。真实服务集中在独立“农场助手”界面。

## 规则与存档

- 完整 278 项 TypeScript 测试通过，新增 11 项小镇规则测试。覆盖旧存档/备份迁移、严格校验、不可变输入、列车冷却/人数上限、可生产商品来源、缺货原子性、接待容量、计时边界与回拨、一次领奖、建造升级成本、真实资料键隔离和数值溢出。
- 每班最多三位模拟访客，间隔五分钟，小镇最多六位；没有自动到站、交货、消费钻石或自动领奖。需求仅来自有实际来源的游戏商品，排除采矿材料和枯树提供的不可再生产水果。
- 原始存档缺少小镇字段时添加初始设施；存在但不合法的小镇数据不静默重置，沿用原始资料恢复副本保护。设施、声望、访客与服务计时写入游戏存档和游戏备份。

## 限制

没有 Android 真机触控、系统文件选择、图库/相机、离线语音、定位精度、本地模型性能或系统覆盖安装验证。浏览器和桥接模拟不能证明硬件功能已通过。

游戏为原创单机原型，未实现 Hay Day 的全部内容、多人社区、跨玩家交易或账号同步。模拟游客的需求和游戏报酬不是现实市场需求；不用于真实经营结论。通用本地模型没有经本应用农学或兽医学专项验证的诊断准确率，不能替代现场专业检查。
